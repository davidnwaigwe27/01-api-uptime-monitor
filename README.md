\# API Uptime Monitor



A simple web application for monitoring website and API availability.



\## Project Overview



API Uptime Monitor allows users to register URLs, check whether endpoints are online, track response times, and view check history.



\## Technology Stack



\- \*\*Frontend:\*\* HTML, CSS, Vanilla JavaScript

\- \*\*Backend:\*\* Python, FastAPI

\- \*\*Database:\*\* Supabase PostgreSQL

\- \*\*Scheduler:\*\* Python-based scheduled checks

\- \*\*Frontend deployment:\*\* Vercel

\- \*\*Backend deployment:\*\* Render

\- \*\*Version control:\*\* Git and GitHub



\## Planned Features



\- Register and manage monitored URLs

\- Check endpoint availability

\- Record HTTP status codes and response times

\- Display current endpoint status

\- View historical check results

\- Display summary statistics on a dashboard
